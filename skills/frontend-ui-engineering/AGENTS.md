# AGENTS.md - Frontend UI Engineering skill

Use this skill for user-facing UI: pages, components, dashboards, forms,
responsive behavior, accessibility, and visual polish.

Essentials:

- Read existing design tokens and nearby components before inventing new UI.
- Declare product fit and design-system tokens before writing substantial UI.
- Avoid generic AI aesthetics: purple gradients, oversized rounded cards, stock
  bento grids, fake content, and emoji icons.
- Build all states: loading, empty, error, focus, disabled, success, and
  validation where relevant.
- Verify keyboard access, focus, contrast, mobile widths, reduced motion, and
  browser console output.

Full guide: `SKILL.md`.
